# R20260908: 추세 보유 개선 사전 계획

사용자가 승인한 범위: 기존 오류 수정 준비, 버전별 기록, 원인 분석, 소수 후보의 로컬 실험과 재검증. 서버 변경·실전 활성화·원격 push·main 병합은 별도 결정입니다.

## 가설과 후보

기준 118회 거래 중 추적 손절은 50회입니다. 그중 36회는 매도 후 7일의 마지막 종가가 매도가보다 높았습니다. 이는 사후 관찰이며 보유했을 때의 실제 수익이나 인과 효과를 증명하지 않습니다. 가격 경로·재진입·기회비용을 반영한 전체 재실험으로 확인합니다.

결과를 보기 전에 다음 세 가지를 고정합니다. 후보를 추가하거나 좋은 구간만 고르지 않습니다.

| ID | 변경 | 가설 |
| --- | --- | --- |
| baseline | 기존 설정 | 재현성과 비교 기준 |
| trail_4atr | 추적 간격 3 ATR → 4 ATR만 변경 | 일시적 흔들림 때문에 상승에서 이탈하는 일을 줄일 수 있는가 |
| activate_3r | 추적 시작 +2R → +3R만 변경 | 충분한 상승이 생긴 뒤 보호를 시작하면 순수익과 낙폭의 균형이 나아지는가 |

초기 손절 2.5 ATR, 거래당 위험 2%, 최대 노출 70%, 낙폭 사건 기준 15%, 자동 복구, 진입과 채널 청산 및 보유기간 조건은 그대로입니다. 후보의 기본 전략 채택은 자동으로 하지 않습니다.

## 시험

- 데이터: 기존 공개 KRW-BTC 4시간봉, 2019-09-07T04:00:00Z부터 2026-09-07T04:00:00Z 미만. 정확한 첫·끝 행과 파일 해시는 실행 기록으로 확인합니다.
- 7년 전체 백테스트: 세 후보 × 기본/0.20% 불리한 체결, 편도 수수료 0.05%.
- 시간분리: 기존 2년 TRAIN / 5일 공백 / 다음 3개월 OOS, 19개 구간. 세 후보와 두 비용으로 TRAIN·OOS 모두 실행합니다. 구간마다 초기 100·미보유·말일 청산. 지표는 각 구간 끝 이전 자료만 사용합니다.
- 기존 검증기의 요청 생성·결과 대사·OOS 연결을 재사용합니다. 고정 9개 trial 공식 검증 레지스트리는 수정하지 않습니다. 신규 3개 연구 비교를 공식 PASS로 표시하지 않습니다.
- 이 7년 데이터와 OOS는 이미 본 자료입니다. 수정 후 수치는 새 미관측 검증이 아닌 탐색 결과입니다. 과거 9개 시도에 이번 두 후보가 추가되므로 기존 DSR/PBO를 신규 후보의 점수로 재사용하지 않습니다.
- 실험 중단 후 동일 manifest와 결과 해시가 맞는 완료 셀은 재사용하고, 불완전·실패 셀은 숨기지 않습니다. 기존 결과와 출력 폴더를 무단 교체하지 않습니다.

## 채택·보류 기준

전체 및 OOS 기본 비용 순수익이 기준보다 높고, OOS 최대 낙폭이 15% 이하이며, 스트레스 순수익 양수·수익 구간 비율 악화 없음·거래 표본과 과적합 근거가 충분한지를 함께 확인합니다. 연구 후보의 비교 우위와 실전 적합성은 분리합니다. 공식 기준 미충족이나 신규 과적합 검증 부재는 채택 보류 사유입니다. 실패를 성공으로 바꾸려고 합격선을 낮추지 않습니다.
