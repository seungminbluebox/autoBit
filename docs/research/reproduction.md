# 결과 보관과 다시 실행하는 방법

이 안내는 개발자와 다음 작업을 이어받는 AI를 위한 것입니다. 사용자가 직접 백테스트를 실행할 필요는 없습니다.

## 코드가 바뀌어도 당시 전략 찾기

보고서에는 전략 ID와 실험 ID를 구분해 적습니다. `experiment.json`은 당시 Git 커밋, 전체 전략·위험·비용 설정, 기간 분할, Python·라이브러리 버전, 입력·추적 파일 해시를 담습니다. `source.zip`에는 그때의 추적 코드·문서·테스트·의존성 잠금 파일이 들어갑니다. `processed.csv.gz`와 `quality.json`은 해당 시험에 실제 사용한 입력입니다.

현재 전략 파일의 내용으로 옛 보고서를 해석하지 않습니다. 해당 커밋의 코드와 그 실행의 설정을 사용합니다. 같은 코드에서도 설정이 다르면 다른 후보입니다. `baseline`, `trail_4atr`, `activate_3r`는 각각 전체 설정으로 기록되며, 독립 OOS 파일에도 후보 ID가 명시됩니다.

## R20260908 실행

검증된 실행 코드 커밋은 `c61a74f66a1b1f2871c32d3c06e03c4e8486c2b5`입니다. 연구 문서의 후속 커밋과 구분합니다. 해당 커밋을 별도 로컬 작업 폴더에 꺼내 Python 3.12와 `uv.lock`의 의존성을 준비합니다. 기존 모의매매 서비스나 원장을 대상으로 실행하지 않습니다.

후속 `97d9489`는 버전 정보 수집을 저장소 안전 검사에 맞게 분리한 도구 보완입니다. 기존 실험 산출물과 그 소스 사본은 수정하지 않았습니다. 후속 코드로 새 실험을 시작하면 새 출력 폴더를 사용해야 하며, 기존 `c61a74f` 결과를 이어하려면 당시 커밋과 환경으로 복구해야 합니다. 전체 검사와 보완 검사의 범위는 [검증 기록](verification.md)에 남겼습니다.

작업 폴더에서 올바른 소스를 명시합니다. 공유 Python 환경이 다른 체크아웃을 가리키면 실행기가 계산 전에 거부합니다.

```powershell
$env:PYTHONPATH = (Resolve-Path 'src').Path + ';' + (Get-Location).Path
$env:PYTHONDONTWRITEBYTECODE = '1'
python -m tools.research.run_experiment --input data/processed/krw-btc-7y-20260907T040000Z/processed.csv --output reports/new-unique-research
```

실제 실행의 입력과 출력은 공용 데이터 폴더를 상대 경로로 지정했습니다. 다른 위치에서 복구할 때에는 입력 gzip을 새 폴더에 풀고 같은 폴더에 보존된 `quality.json`을 둡니다. 그 파일들의 해시가 기존 `experiment.json`과 맞는지 먼저 확인합니다.

## 중단 후 이어하기

같은 체크아웃·설정·환경·입력으로 같은 출력 경로에 `--resume`을 추가합니다. 완료 셀의 해시와 실험·후보·비용·구간·설정 식별값을 검사한 후 재사용합니다. 미래 구간 가격이 과거 지표에 반영되지 않는지도 테스트합니다.

원래 폴더가 존재하는데 `--resume`이 없으면 거부합니다. 다른 코드·환경·입력의 manifest, 변조된 셀, 불완전한 결과는 섞지 않습니다. 파일과 체크섬 기록 사이에 중단된 셀은 보존한 뒤 조사합니다. 전체 기간 보고서는 임시 디렉터리에서 완성한 뒤 게시하므로 부분 파일을 완료 보고서로 취급하지 않습니다. 실패 기록과 남은 임시 디렉터리는 무단 삭제하지 않습니다.

이번 `exit-comparison-v1`은 초기 도구의 출처·재개 검증 보강을 위해 중단한 예비 실행이며 완료된 전략 실험이 아닙니다. 원본을 보존하고, 보강된 버전의 정식 연구 출력은 `exit-comparison-v2`로 구분합니다. 여기서 v2는 도구 실행 묶음 버전이며 채택된 전략 v2라는 뜻이 아닙니다.

## 어떤 파일을 읽는가

| 파일 | 내용 |
| --- | --- |
| `comparison.json` | 세 후보·두 비용의 전체 기간과 시간분리 성적 |
| 후보별 `summary-*.json` | 전체 성적, OOS 성적, 19개 구간별 수치 |
| 후보별 `full-*/` | 7년 수익 요약, 거래·주문·자산곡선 CSV와 품질·manifest |
| 후보별 `fold-*.json.gz` | TRAIN/OOS 원시 모의 거래·주문·자산 기록, 실행 식별값 |
| 후보별 `oos-*.json` | 후보·비용 식별값과 연결된 OOS 자산곡선·수익률 |
| `SHA256SUMS.json` | 완성된 묶음의 파일별 무결성 검사값 |

모든 원시 기록은 과거 공개 가격으로 만든 모의 기록입니다. 실제 OCI 원장·환경변수·키·알림 로그는 이 묶음에 포함하지 않습니다. 이 연구는 기존 공식 9개 trial 판정을 대체하지 않고, 신규 후보에 과거 DSR/PBO나 PASS를 붙이지 않습니다.

## 보관 한계

묶음은 현재 로컬 `reports/research-20260908/`에 보존되며 Git 추적 대상이 아닙니다. 별도 원격 백업은 수행·검증하지 않았습니다. 코드 커밋과 문서 보존, 데이터·상세 결과의 원격 백업은 서로 다른 작업입니다. 원격 게시 시에는 모의 결과인지와 공개 정보 정책을 검토하고 승인된 저장소에 별도로 보관해야 합니다.
