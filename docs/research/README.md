전략 버전은 규칙 묶음, 실험 번호는 특정 데이터·비용·검증 조건의 시험을 뜻합니다. 채택되지 않은 후보도 삭제하지 않습니다. 각 실행에는 Git 커밋, 전체 설정, 데이터 SHA256, 의존성 잠금 파일, 실행 코드 사본과 결과 파일을 연결합니다. 기존 결과는 덮어쓰지 않습니다.

큰 결과 묶음은 저장소 루트의 `reports/research-20260908/`에 보관합니다. 이 폴더는 Git 제외 대상이며 아직 원격 백업된 것이 아닙니다. 보고서의 체크섬은 파일 식별·변조 확인 수단이며 백업을 대신하지 않습니다. 공개 문서는 요약·방법·상대 보관 경로만 포함합니다. 위키는 별도 브랜치이므로 이 문서는 먼저 README에서 연결하고 위키 통합은 별도 검토합니다.
