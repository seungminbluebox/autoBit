# 기준 전략 v1 — R20260907 및 재현 R20260908

상태: 모의매매 연구 기준, 실전 미승인. 현재 소스 커밋 `f719dae`는 백테스트 오류 수정이며 매매 규칙 변경이 아닙니다. 이 페이지의 v1은 연구 문서 버전으로, 위험 원장 payload v1/v2와 다릅니다.

## 전략의 생각

KRW-BTC의 큰 상승 추세에 참여하고 하락·불확실 구간에서는 현금을 보유하여, 비용을 뺀 수익과 최대 하락의 균형을 검증합니다. 단순 보유보다 반드시 수익이 커야 한다거나 매일 거래한다는 전략은 아닙니다.

## 당시 규칙

| 항목 | 규칙 |
| --- | --- |
| 시장·봉 | 업비트 KRW-BTC, 확정 4시간봉, 매수 후 전량 청산하는 단일 포지션 |
| 진입 | 미보유·미처리 주문 없음·정상 데이터·워밍업 완료, 종가가 EMA200과 직전 50봉 최고가보다 높음, 이전 종가는 이전 채널 상단 이하 |
| 지표 | EMA200, 현재 봉 제외 Donchian50/20, ATR14, 워밍업 600봉 |
| 체결 | 확정봉 판단 후 다음 봉 시가 시장가 모사, 손절·가격 gap은 실행 어댑터 규칙 적용 |
| 최초 손절 | 실제 체결가 − 2.5 × 진입 시 ATR |
| 수익 보호 | +2R 도달 후 다음 봉부터 max(기존 손절, 진입가, 최고가 − 3ATR), R은 최초 손절까지의 가격 거리 |
| 채널 청산 | 확정 종가가 이전 20봉 최저가보다 낮음 |
| 정체 청산 | 60봉 이상 보유 AND 보유 중 최고가가 +1R 미달 |
| 최장 보유 | 1,095봉에서 청산 판단, 고정 최소 보유기간 없음 |
| 정상 위험 | 계좌 위험 예산 2%, BTC 명목금액 상한 70%, 변동성·현금·비용 제약 반영 |
| 낙폭·복구 | 최고 평가자산 대비 15% 사건에서 정리·72시간 중단, 조건 충족 후 위험 0.25%·노출 15%로 시작하여 단계적 자동 회복 |
| 기타 제한 | 일간 손실 4%, 주간 축소 5%·중단 7%, 연패·변동성·시스템 상태의 독립 제한. 더 엄격한 조건 우선 |
| 비용 | 기본 편도 수수료 0.05% + 불리한 체결 0.05%, 스트레스 체결 0.20% |

2%는 BTC 가격 손절폭이나 손실 보장 상한이 아닙니다. 15%도 중단 작동 기준이며 gap·지연으로 넘어갈 수 있습니다. 보호 손절·위험 강제 청산이 보유기간 연장보다 우선합니다. 실패 후 자동 회복은 기존 사건 시각·원장 증거를 보존합니다.

규칙의 상세 당시 소스는 `src/autobit/config.py`, `core/engine.py`, `core/risk_state.py`, `strategy/donchian_trend.py`, `risk/position_sizer.py`입니다. 세 환경은 같은 코드·설정으로 실행할 때 같은 공통 판단을 사용하며, 실전 진입은 잠겨 있습니다.
